# Generate C# bindings for wasmtime-c-api

__Prerequisites;__
- `cargo` for Rust csbindgen
- `clang` for Rust bindgen
- `git` for cloning wasmtime repo for XML generation
- `cmake` to generate XML docs with doxygen
- `doxygen` to generate XML docs
- `dotnet` for C# Rewriter

__./gen.sh__

This file is intended for use with GH actions, which aren't created yet. \
It follows the exact same instructions laid out below;

__Generate the bindings;__

- Obtain the c-api from wasmtime releases; \
  https://github.com/bytecodealliance/wasmtime/releases
- Generate C# bindings; \
  `cargo run --manifest-path ./wasmtime-csbindgen/Cargo.toml ./wasmtime-v44.0.2-x86_64-windows-c-api`
- Observe new file `NativeWasmtime.g.cs`

__Add documentation to generated bindings;__

- Clone wasmtime repo with tag for version; \
  `git clone https://github.com/bytecodealliance/wasmtime.git --branch v44.0.2 --depth 1`
- Edit `wasmtime/crates/c-api/doxygen.conf.in`
  - Change `GENERATE_XML` to `YES`
  - Change `WARN_AS_ERROR` to `NO`  (not sure why it errors but it's benign)
- Generate XML; \
  `cmake -S wasmtime/crates/c-api -B wasmtime/target/c-api && cmake --build wasmtime/target/c-api --target doc`
- Rewrite to include documentation generated by doxygen; \
  `dotnet run --project WasmtimeCsbindgenRewriter/WasmtimeCsbindgenRewriter/WasmtimeCsbindgenRewriter.csproj NativeWasmtime.g.cs wasmtime/crates/c-api/xml`
- Observe new file `NativeWasmtime.g.g.cs` which now contains doc comments.
